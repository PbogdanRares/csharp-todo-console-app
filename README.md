# C# TODO Console App

A simple console-based TODO application built while learning C# and .NET fundamentals.

## About the Project

This project was created as one of my first C# applications while transitioning from C++ algorithmic programming toward C# and .NET development.

The main goal was to practice writing program logic independently, validating user input, working with collections, and refactoring code into smaller methods.

## Features

- View all TODO items
- Add new TODO items
- Prevent empty task descriptions
- Prevent duplicate task descriptions
- Remove TODO items by their displayed index
- Validate numeric input with `int.TryParse`
- Handle invalid menu choices
- Prevent removal when the task list is empty

## Concepts Practiced

- C# methods
- `List<string>`
- Loops and conditional statements
- Input validation
- `int.TryParse` and `out`
- String validation
- List indexing
- Guard clauses and early returns
- Separation of responsibilities
- Basic refactoring
